Participants work through prepared questions and the agent's answers; they do not compose their own questions. The mode keeps the answer view and basic 3D navigation (rotate, zoom, floor selection, selecting an object to see its name) and hides live dashboards, device control, alerts and settings, so that every participant sees the same screens and no participant can operate real equipment. |

| 2026-11-23 | Decision: two measurements are added for December. (1) One model is onboarded again from scratch while the time of each step and every manual intervention are recorded. | 2026-11-23 | Scope: a third venue that required an RDF graph is dropped, because the graph is a property graph that is only partly aligned with a standard building vocabulary. |
| 2026-11-23 | Scope: the January manuscripts use material from one site only. Conversion statistics from a second site, which had been planned as supporting evidence, are left out; the timed onboarding is run on the first site's model. |
| 2026-11-24 | Evaluation hygiene: the 60-question set is withheld from the developers until the evaluated build (model snapshot, prompt, graph) is frozen. One developer reviews the reference answers once, after the freeze. After the freeze, incorrect answers are logged and not fixed. Reason: the developers tune the system on their own question set; showing them the evaluation questions before the freeze would measure a system tuned to those questions. |
| 2026-11-24 | Ablation definition: in the setting without relation tracing, the two traversal tools are disabled and the relation fields that the property tool returns alongside an object (containing space, served space, parent system) are removed as well. Native object properties and the sensor-to-equipment bindings of the device registry are kept in both settings. The two prompts differ only in the sentences that mention the removed tools; both are frozen on the same day and the prompt version is logged per run. Reason: a code review showed that relation information would otherwise reach the agent through the property tool. |
| 2026-11-24 | Trial procedure: the two-minute limit covers the time from showing the answer to the accept/reject choice. When it expires the participant is prompted and the trial waits for the choice; the trial is flagged as overtime and the actual time is logged. The localisation step ends with one confirmed object or an explicit "not found" response. The runs are executed by the developers from a question file handed over after the freeze; a run is repeated only after an infrastructure failure, and the repetition is logged. |
