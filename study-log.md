| 2026-11-24 | Ablation definition: in the setting without relation tracing, the two traversal tools are disabled and the relation fields that the property tool returns alongside an object (containing space, served space, parent system) are removed as well. The two prompts differ only in the sentences that mention the removed tools; both are frozen on the same day and the prompt version is logged per run. Reason: a code review showed that relation information would otherwise reach the agent through the property tool. |
| 2026-11-24 | Trial procedure: the two-minute limit covers the time from showing the answer to the accept/reject choice. The localisation step ends with one confirmed object or an explicit "not found" response. The runs are executed by the developers from a question file handed over after the freeze; a run is repeated only after an infrastructure failure, and the repetition is logged. |

| 2026-11-28 | Reference answers: the reference answers for the 60-question set were written before any run, from the inventory snapshot of 2026-11-27. A script derives, for each question, the set of 3D objects that should be highlighted and the points whose values are read independently at run time; it stops if the inventory counts change. Scoring rules fixed in the same file: (1) a value in an answer matches when it equals the collected value just before or just after the question was submitted (the collected values are exported once after the runs, by a route separate from the assistant); (2) each object set has required objects and allowed additions, and highlight precision and recall are computed after the allowed additions are removed; (3) for questions on simulated values, whether the answer discloses that the value is simulated is recorded separately from correctness; (4) a measured-scope question answered from a simulated point without saying so gets no credit, and partial credit if the answer says so; (5) two open-ended questions have written rubrics. Four lookup questions cannot be given reference answers from the inventory alone (space lists and areas are not in it); they are completed after the version freeze, before the questions are sent to the developers. |
