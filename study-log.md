| 2026-11-22 | Decision: the agent may run on a commercially hosted language model. One model is chosen; its dated version identifier and its settings (such as temperature) stay fixed for the whole evaluation and are written to every run log and to the manuscript. |
| 2026-11-22 | Decision: the evaluated build (model, prompt and graph versions) is frozen on 2026-12-05, or on 2026-12-11 at the latest, before the question-set runs start. If the later date is used, the steps that follow move by one week. Development continues on a separate branch after the freeze. |
| 2026-11-22 | Decision: the question set is held out. Developers improve the system with their own everyday questions and do not tune it on the evaluation questions. Reference answers are written before the runs. |
| 2026-11-22 | Decision: sessions run in an evaluation mode of the twin on a prepared computer, with a facilitator present. Participants work through prepared questions and the agent's answers; they do not compose their own questions. The mode keeps the answer view and basic 3D navigation (rotate, zoom, floor selection, selecting an object to see its name) and hides live dashboards, device control, alerts and settings, so that every participant sees the same screens and no participant can operate real equipment. |
| 2026-11-22 | Decision: a facilitator may be replaced after consulting the current facilitators. Whoever facilitates a session cannot take part as a participant; developers of the system remain excluded. |
